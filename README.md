## 🛠️ Technology Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React + custom high-precision brand SVGs (`Icons.jsx`)
- **Interactions**: Canvas Confetti, Framer Motion
- **Asset Processing**: PDF-Lib

## 💻 How to Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Harishkumar-L/<repo-name>.git

# 2. Navigate to project directory
cd <repo-name>

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```

## 📤 How to Push to GitHub

1. Create a new repository on your GitHub account ([github.com/new](https://github.com/new)) named `portfolio` or `harish-kumar-portfolio`.
2. In your terminal inside the project folder, run:
```bash
git branch -M main
git remote add origin https://github.com/Harishkumar-L/<your-new-repo-name>.git
git push -u origin main
```
